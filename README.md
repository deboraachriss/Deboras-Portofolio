# Portofolio Debora Chrisdiar Ayomi

Website portofolio pribadi yang dibuat menggunakan HTML, CSS, dan JavaScript.

## Struktur folder

```text
.
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── gambar dan dokumentasi proyek
```

## Menjalankan website

Tidak perlu instalasi atau build tool. Buka `index.html` melalui browser untuk melihat website.

## Mengubah konten

- Konten, tautan, dan daftar proyek ada di `index.html`.
- Warna, ukuran, jarak, dan tampilan responsif ada di `style.css`.
- Filter proyek, menu ponsel, dan penanda navigasi ada di `script.js`.
- Gambar website disimpan di folder `assets`.

## Deploy ke Vercel

1. Upload seluruh isi folder ini ke repository GitHub.
2. Import repository tersebut dari dashboard Vercel.
3. Pilih Framework Preset `Other`.
4. Biarkan Build Command dan Output Directory kosong.
5. Klik Deploy.

Pastikan `index.html` berada di direktori utama repository.
